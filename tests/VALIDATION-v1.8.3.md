# v1.8.3 验证记录

日期：2026-11-08。

## 移动端布局与编辑

Chrome 独立视口容器使用本地合成图片检查。以下 13 组全部通过：320×568、375×667、375×812、390×844、393×852、402×874、414×896、430×932、440×956、667×375、844×390、932×430、390×400（较矮可视区域）。

每组覆盖：

- 作者和检查更新按钮同一行，步骤条保持单行，无页面横向溢出。
- 常见竖屏首屏的主操作可见；320×568 下“下一步”底边约为第 447 CSS 像素。
- 第三步独立编辑界面在视口内，固定保存入口可触达。
- 水印与遮盖设置展开时仍可见预览；设置区可单独滚动、收起。
- 修改文字后立即更新预览，并自动将预览移到当前水印位置。
- 缩放加减、适合宽度及比例 UI 已移除，双指缩放仍可运行。
- 缩放后的遮盖坐标准确，直接点击遮盖改色保留。
- 返回保留水印文字和遮盖，保存说明可从“更多”打开。
- 可见编辑按钮高度至少 44px。

另在 390×844 容器进行浏览器原生点击、启用水印、替换文字、返回设置和返回第一步的交互与视觉检查。

## 回归检查

`node tests/release.cjs` 通过，覆盖版本比较、缓存隔离及原子安装、更新确认/暂缓/忙碌锁定和重新载入。editor.js、updates.js、sw.js 以及 index.html 内联脚本通过语法检查。DOM 控件 ID 唯一，本地资源引用存在。

拼接核心 core.js、导出和遮盖模块 extras.js、分步状态模块 flow.js 不改；原视频生成代码与系统分享处理函数保持不变。旧版本及此前验证记录保留。

## 限制

触控测试使用合成 Pointer Events 并替代 Pointer Capture 的硬件前提；不代表真实多点触控设备实测。390×400 检查是较矮视口布局模拟，不能代替真实软键盘验证。当前没有真实 iPhone / iOS Safari，安全区域和键盘可视区域由 CSS 环境变量与 VisualViewport 适配，仍建议实机验收。
