# 老杨的长截图工具 v1.8.3

浏览器本地处理滚动录屏，自动识别重叠区域并尝试拼接长截图。作者：老杨。

## 在线使用

[打开长截图工具](https://jingluo2017.github.io/long-screenshot/) · [项目源码](https://github.com/JingLuo2017/long-screenshot)

公开网页无需登录 GitHub 或 ChatGPT。首次打开需要联网；页面提示离线就绪后可尝试断网使用。

## 使用方法

选择录屏 → 设置画面区域并生成 → 编辑水印、遮盖隐私并保存或分享。素材在设备本地处理，不上传录屏或图片。

- 水印支持日期时间或自定义文字，实时预览。
- 隐私遮盖支持颜色选择、拖动移动及四角缩放。水印位于遮盖上层。
- 支持返回、确认后清空、添加到主屏幕及首次联网缓存后的离线使用。
- iPhone 请优先用 Safari，保存由系统分享菜单完成。

## GitHub Pages 部署

仓库 Settings → Pages → Source 选择 Deploy from a branch → 选择 main 和 / (root) → Save。无需构建、后端或 API 密钥。

预期网址：https://jingluo2017.github.io/long-screenshot/

## 已知限制

视频最长 90 秒；快速滚动、动画或重叠不足仍可能导致遗漏、重复或断裂。生成后请检查图片。浏览器对离线缓存、图片尺寸及保存的支持存在差异。

此迁移保留 v1.8.1 的功能与拼接算法，未处理暂缓的两处拼接重复问题。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面与录屏读取、长图生成及保存入口 |
| `core.js` | 重叠匹配与拼接算法 |
| `extras.js` | 水印、隐私遮盖与主屏幕入口 |
| `flow.js` | 三步操作流程与状态保留 |
| `sw.js` | 本地离线缓存 |
| `manifest.webmanifest` | 主屏幕应用配置 |

## 隐私说明

本应用不上传用户选择的录屏、生成的图片或编辑内容，不需要 API 密钥。网页由 GitHub Pages 提供，访问网站仍会向托管平台发送正常网页请求。关闭或刷新页面后，不保留本次录屏和编辑结果。

## v1.8.1 更新

- 新版本弹窗展示版本号和更新说明，可暂不更新或关闭，通过页面提示或底部入口再次打开。生成及图片同步期间暂不可更新；更新会重新载入，已有内容时再次确认。

## 后续发布规则

每次发布使用新的三段式版本号，并同步修改 version.json（版本与更新说明）、updates.js 的 VERSION、sw.js 的 VERSION 与资源清单、index.html 的 app-version 及资源版本。已发布的资源版本号不要复用。推送 main 后等待 Pages 成功，已有页面会联网检查更新。旧 v1.8 首次升级需要联网刷新一次，以加载新更新机制。

## 检查

在仓库根目录执行 `node tests/release.cjs`，验证版本比较、缓存作用域、原子安装、暂不更新/关闭、处理期间锁定、数据丢失确认及更新重载。浏览器尺寸检查覆盖 320–440 像素宽的常见 iPhone 竖屏和常见横屏；这些检查不能代替真实 iOS Safari 的设备测试。

## v1.8.3 更新

- 检查版本更新移到页面上部，与作者信息同一行。三步进度使用紧凑单行。
- 第三步进入独立编辑界面，顶部返回、清空和保存固定可见。下方工具展开时，预览保持可见；再次点击工具可收起设置。横屏或大屏使用预览与设置并排布局。

- 使用可视视口高度适配软键盘变化，并保留安全区域间距。返回保留参数、遮盖和水印，清空仍需确认。

修改水印或切换水印位置时，预览自动定位到对应位置；原始导出尺寸不受预览缩放影响。使用说明与离线说明折叠收纳，功能仍完整保留。
