## 使用方法

选择录屏后，时长和可读性检查通过即可用推荐设置生成；也可以按需调整画面区域和图片格式。生成后进入“编辑保存”，可添加水印、遮盖隐私，再保存或分享。素材在设备本地处理，不上传录屏或图片。

- 水印支持日期时间或自定义文字，实时预览。
- 默认单指拖动查看；点「框选遮盖」开启编辑，再点一次回到查看。开启后单指绘制或调整遮盖，轻点改色，点红色垃圾桶移除当前遮盖。两种状态都支持双指滑动和捏合。水印位于遮盖上层。
- 支持返回和确认后清空。
- iPhone 请优先用 Safari，保存由系统分享菜单完成。

## 已知限制

视频最长 90 秒；快速滚动、动画或重叠不足仍可能导致遗漏、重复或断裂。生成后请检查图片。浏览器对图片尺寸及保存的支持存在差异。

此迁移保留 v1.8.1 的功能与拼接算法，未处理暂缓的两处拼接重复问题。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与保存入口 |
| `crop.js` | 录屏裁剪预览及画面范围设置 |
| `generation.js` | 录屏预检、分阶段生成及取消 |
| `core.js` | 重叠匹配与拼接算法 |
| `extras.js` | 水印、隐私遮盖与主屏幕入口 |
| `flow.js` | 三步操作流程与状态保留 |
| `manifest.webmanifest` | 主屏幕应用配置 |

## 隐私说明

本应用不上传用户选择的录屏、生成的图片或编辑内容，不需要 API 密钥。网页由 GitHub Pages 提供，访问网站仍会向托管平台发送正常网页请求。关闭或刷新页面后，不保留本次录屏和编辑结果。
